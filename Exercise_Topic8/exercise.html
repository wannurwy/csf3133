Practical Activity: Student Profile & Marks Dashboard

Build the functionality of a student dashboard using JavaScript. The HTML structure and CSS design are provided — your task is to write the JavaScript code.

JavaScript (Part 2) Work in pairs Ungraded activity

Getting Started

Download both starter files below and save them in the same project folder. Then create a new file named script.js in that folder.

index.htmlHTML page structure
Download HTML
style.cssDashboard appearance
Download CSS
Important: Do not create or submit another HTML or CSS file. Your main task is to implement the required functionality in script.js. The provided HTML already contains a script reference to script.js.

Scenario

You are required to develop a web page that displays a student's profile and academic results. The dashboard should show the student's personal information, course marks, average marks and highest marks.

Activity Requirements

Complete all five tasks using JavaScript.

1

Create a Student Object

Create a JavaScript object named student with the following properties:

  • Student name
  • Matric number
  • Programme

Use the object to display the student's information in the Student Profile section of the dashboard.

2

Create an Array of Course Marks

Create an array named courses to store at least four courses. Each course must contain a course name and marks obtained.

Use an appropriate JavaScript data structure to organise the course information.

3

Display the Course Results

Use a loop to retrieve and display all course information from the courses array.

Display the results in the HTML table provided in index.html, including the number, course name and marks.

4

Calculate the Academic Results

Write JavaScript statements to calculate and display:

  • Average Marks: Calculate the average marks obtained for all courses.
  • Highest Marks: Identify the highest mark among all courses.

Display both results in the Academic Summary section of the dashboard.

5

Implement the Dashboard Functionality

Use DOM manipulation to display the student information, course results and calculated academic results on the web page.

Ensure that the dashboard displays the correct information when the page is loaded.

Additional Challenges (Optional)

If you have completed all five tasks, try the following challenges:

  1. Use the Date object to display the current date.
  2. Use a for...in loop to display all properties of the student object.
  3. Implement the Remove Last Course button using the pop() method. Update the course table and academic summary after removing the last course.

Submission & Demonstration

  1. Save script.js in the same folder as the provided HTML and CSS files.
  2. Ensure that all JavaScript functions work correctly in a web browser.
  3. Demonstrate your completed dashboard to the lecturer.
  4. Be prepared to explain the JavaScript concepts and methods used in your implementation.
Reminder: This is an ungraded practical activity. The objective is to practise JavaScript programming and understand how objects, arrays, loops and DOM manipulation work together in a simple web application.
