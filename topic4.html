New Features in HTML5

A hands-on tour of HTML5 features. Explore each example and try it yourself.

Graphics

1. Canvas

Draw graphics dynamically using JavaScript.

View Code Example 
<canvas id="myCanvas"
        width="300" height="140">
</canvas>

<script>
const canvas =
    document.getElementById("myCanvas");
const ctx = canvas.getContext("2d");

ctx.beginPath();
ctx.arc(150, 70, 40, 0, 2 * Math.PI);
ctx.fillStyle = "royalblue";
ctx.fill();
</script>

Play media directly in the browser using native HTML elements.

Example video. Internet access is required.

View Code Example

    <source src="sample.mp4"
            type="video/mp4">
</video>

<audio controls>
    <source src="sample.mp3"
            type="audio/mpeg">

Web Storage

3. Local Storage

Save small amounts of data in the browser for later use.

Your saved name will appear here.

View Code Example 
// Save data
localStorage.setItem("name", "Ali");

// Retrieve data
const name = localStorage.getItem("name");

// Remove data
localStorage.removeItem("name");

Validation

6. Better User Experience

Built-in validation helps users provide valid information.

View Code Example

       minlength="4"
       required>

Key Takeaway

HTML5 introduces native media, graphics, semantic elements, browser storage and improved form controls to make web development more powerful and user-friendly.
