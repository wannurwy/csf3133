01
Object fundamentals

JavaScript objects

Representing entities through properties and methods

An object is a way of modelling something. In JavaScript, an object is a collection of properties and values. Objects can also contain methods (functions associated with the object).

Object

The entity being represented, such as a car, book or customer.

Properties

Describe the object, such as a car's colour, weight or model.

Methods

Describe actions the object can perform, such as start() or stop().

Real-life example: A car

Object

Car

Properties

Colour: blue
Weight: 1,200 kg

Methods

start()
stop()

Different cars can share the same property names and methods, but their property values may differ.

How do we access object members?

var mySubject = new String("CSF3133");

mySubject.length;       // property: 7
mySubject.indexOf("CSF"); // method: 0
Object groupDescription
User-defined objectsCustom objects created by the programmer.
Built-in objectsObjects provided by JavaScript itself.
Browser objectsObjects supported by the browser environment.
Document objectsObjects that are part of the DOM and provide a structured interface to HTML and XML documents.
Why are objects useful? They group related data together. For example, a book's ISBN, title, author and publisher can be stored in one book object.

Creating objects

Object constructor and literal notation

Two ways to create an object and assign its properties

Method 1: Object constructor

var book = new Object();
book.ISBN = "9781492055709";
book.Title = "JavaScript Cookbook";
book.Author = "Adam D. Scott, Matthew MacDonald, Shelley Powers";
book.Publisher = "O'Reilly Media, Inc.";

Method 2: Object literal notation

var book = {
  ISBN: "9781492055709",
  Title: "JavaScript Cookbook",
  Author: "Adam D. Scott, Matthew MacDonald, Shelley Powers",
  Publisher: "O'Reilly Media, Inc."
};
Both examples create a book object with the same four properties. Literal notation places the property names and values inside curly braces.

03
Reusable object patterns

Constructor functions

Create multiple object instances with the same property structure

A constructor function can be used to create reusable code for objects. It defines the properties that each new object instance will have.

function Customer(code, name, type) {
  this.code = code;
  this.name = name;
  this.type = type;
}

var cash_customer = new Customer("CSH1001", "Ahmad", "Cash");
var crd_customer = new Customer("CRD2005", "Ali", "Credit");

The new keyword creates a new instance. The this keyword refers to the object being created.

Object iteration

Display object properties using for...in

Read each property name from an object

var customer = new Customer("CSH1001", "Ahmad", "Cash");

for (var property in customer) {
  document.write(property + ": " + customer[property] + "<br>");
}

The for...in loop iterates over the enumerable property keys of an object. Use bracket notation, customer[property], to access the value using the property name stored in the variable.

Array object

Working with arrays

Store multiple values in one variable

An array is a collection of data or values stored as elements. Each element is accessed using a numeric index. In JavaScript, array indexes start at 0.

grade[0] = "A"grade[1] = "C"grade[2] = "B-"grade[3] = "C+"

Declaring and populating an array

var grade = new Array();
grade[0] = "A";
grade[1] = "C";
grade[2] = "B-";
grade[3] = "C+";

An array can also be created using literal notation:

var grade = ["A", "C", "B-", "C+"];

Try it: Array index explorer

grade[0] = "A"

Loop through an array

var csBook = [
  "Java Programming - A Beginner Guide",
  "HTML5 and Javascript Project",
  "Oracle JDeveloper Handbook"
];

for (var i in csBook) {
  document.write("Book[" + i + "] = " + csBook[i] + "<br>");
}

Array properties

The lecture notes introduce length as an array property. It returns the number of elements in the array.

var csBook = ["Java Programming", "HTML5 and Javascript", "UML"];
document.write(csBook.length); // 3
Important: Setting array.length = 0 removes all elements from that array. The array becomes empty.

Two-dimensional arrays

A two-dimensional array can represent data arranged in rows and columns, such as a marks table.

var marking = [
  [50, 68, 65],
  [78, 65, 60],
  [98, 68, 63]
];

// Access row 1, column 2
marking[1][2]; // 60

Date object

Working with dates and time

Get and manipulate date/time values

The JavaScript Date object provides methods to get and set specific information related to date and time. The current date and time are based on the user's local device.

Creating Date objects

var now = new Date();
var date1 = new Date("March 25, 2014 09:45:15");
var date2 = new Date("March 25, 2014");
var date3 = new Date(2014, 2, 25, 9, 45, 15);
var date4 = new Date(1000);
Month numbering: In the numeric Date constructor, months are zero-based: January is 0, February is 1, and March is 2. This is important when using new Date(year, month, day).

Common Date methods

MethodReturns
getFullYear()Four-digit year
getMonth()Month number (0–11)
getDate()Day of the month (1–31)
getDay()Day of the week (0–6)
getHours()Hour (0–23)
getMinutes()Minutes (0–59)
getSeconds()Seconds (0–59)
getTime()Milliseconds since 1 January 1970

Calculate days until a target date

The lecture example calculates the number of days remaining until a project milestone date.

var today = new Date();
var future = new Date("December 16, " + today.getFullYear());
var different = future.getTime() - today.getTime();
var days = Math.floor(different / (1000 * 60 * 60 * 24));

When the user clicks the link, the browser navigates to the URL specified in the href attribute.

Method 2: JavaScript redirection

JavaScript can change the browser's current location. For example:

window.location.href = "https://example.com";

DOM connection: selecting an HTML element

The lecture objectives include applying the Document Object Model (DOM). The DOM represents the HTML document as objects that JavaScript can access. For example, an element can be selected by its ID and its content can be changed.

<p id="message">Welcome</p>

<script>
  var element = document.getElementById("message");
  element.textContent = "Welcome to JavaScript!";
</script>

The original message is displayed here.

Safety note: The redirect preview does not open an external website. To perform a real redirect in your own project, use window.location.href with the intended destination URL.
