HTML5 overview

Compatibility

Designed for the modern web

HTML5 was intended to remain backwards compatible while introducing new elements and functionality.

Browser support

Supported by modern browsers

Support varies by feature and browser version. Test the controls you use in your target browsers.

03

HTML5 structural elements

Use meaningful elements to describe the purpose of each part of a page.

<body>

Contains the page content shown in the browser.

<header>

Contains introductory content or headings for a page or section.

<nav>

Contains the page's primary navigation links.

<main>

Identifies the main, unique content of the page.

<section> / <article>

Groups related content; an article is suitable for self-contained content.

<aside> / <footer>

aside contains related or complementary content. footer contains footer information.

<body>
↓
<header> · Page heading / branding
<nav> · Main navigation
↓
<main> · Main page content
<section>
Related content
<article>
Self-contained item
<aside>
Complementary
↓
<footer> · Footer information

Example: semantic page skeleton

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Website</title>
</head>
<body>
  <header><h1>My Website</h1></header>
  <nav><a href="#main">Home</a></nav>
  <main id="main">
    <section><h2>Welcome</h2><p>Main content.</p></section>
  </main>
  <footer>Copyright information</footer>
</body>
</html>
Remember: Use <main> for the page's dominant content, and use headings to make the content hierarchy clear.

05

Form element attributes

Attributes determine where data goes and how each control is identified.

AttributeExample / valuePurpose
actionaction="/submit"Specifies the URL that receives the submitted form data.
methodget or postGET appends form data to the URL. POST sends it in the request body; use HTTPS and server-side protections for sensitive data.
idid="email"Unique identifier on the page; useful for CSS, labels, and scripting.
namename="email"Key used when the browser submits a control's value.
requiredrequiredPrevents submission until the required control has a value.
placeholderplaceholder="name@example.com"Shows a hint inside an empty control; it is not a substitute for a label.
name vs id: id identifies an element in the document; name identifies the field in submitted form data. They may use the same text, but they serve different purposes.
<label for="email">Email:</label>
<input type="email" id="email" name="email" required>
06

HTML5 input types

Choose an input type that matches the information expected.

type="email"

Accepts an email-shaped value and provides browser validation.

<input type="email" name="email" required>

type="url"

For a website address. Browsers generally expect a valid URL format.

<input type="url" name="website">

type="tel"

For a telephone number. It does not automatically validate a specific phone-number format.

<input type="tel" name="mobile"
       placeholder="e.g. 0123456789">

type="search"

For search terms. Some browsers add a clear control.

<input type="search" name="keyword">

type="date"

Lets the user select a date using a browser date picker when supported.

<input type="date" name="myDate">

type="number"

For numeric values, optionally limited by min, max, and step.

<input type="number" min="1" max="10">

Try the controls

Example: newsletter form

<h1>Join Our Newsletter</h1>
<form action="/subscribe" method="post">
  <label for="newsletterEmail">Email:</label>
  <input type="email" id="newsletterEmail"
         name="email" required>
  <button type="submit">Sign Me Up!</button>
  <button type="reset">Reset</button>
</form>
07

Datalist, slider, spinner & calendar

Offer suggestions or constrain numeric and date input.

Suggestions

<datalist>

Provides suggested values while still allowing the user to type a different value.

<label for="colour">Favourite colour</label>
<input list="colours" id="colour" name="colour">
<datalist id="colours">
  <option value="Red">
  <option value="Green">
  <option value="Blue">
</datalist>
Slider

type="range"

Lets a user select a value along a range.

<input type="range" min="1" max="100">
Spinner

type="number"

Provides numeric input, often with increment/decrement controls.

<input type="number" min="1" max="10">
Calendar

type="date"

Provides a date picker in browsers that support it.

<input type="date" name="myDate">
