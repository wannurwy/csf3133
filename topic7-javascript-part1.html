Web foundations

Client–server ecosystem

How a browser and a web server communicate

A client (for example, a computer, tablet or phone) requests a web resource using a URL. The web server processes the request and sends a response through the Internet. The browser then displays the returned web content.

1. Client / Browser→2. HTTP request→3. Web server→4. HTTP response→5. Browser renders page
Client

Runs the browser and displays the web page to the user.

Web server

Receives requests and serves web resources or runs server-side scripts.

Support server

May provide supporting services such as mail or database access.

Components of a dynamic website

ComponentExamples / role
Marked-up contentHTML, XHTML and XML describe content and structure.

Images and objectsJPEG images and other embedded objects.

02
Introduction

What is JavaScript?

JavaScript is a programming language commonly used to make web pages interactive and dynamic. It runs on the client side in the web browser and can respond to actions such as clicks, hovers and form input.

Programming language

Used to create dynamic and interactive web content.

Client-side

The browser reads and interprets the code on the user's device.

Works with HTML and CSS

JavaScript can manipulate page content and styling.

Scripting language

Code is interpreted as it runs; a separate compile step is not required in the basic workflow described in the notes.

Three layers of a web page

LayerTechnologyResponsibility
ContentHTMLStructure and content
StylesCSSAppearance and presentation
BehaviourJavaScriptResponse and interaction
Remember: HTML provides the content, CSS controls how it looks, and JavaScript controls how it behaves.

What JavaScript can and cannot do

JavaScript can respond to form elements and links, validate data before submission, change content and styles dynamically, and request resources from a server. The lecture notes also highlight browser and client-computer operations that JavaScript should not directly control, such as launching arbitrary client applications or freely reading and writing local files.

JavaScript has evolved through successive versions and standardisation. The lecture notes introduce several engines associated with browsers and platforms.

EngineAssociation described in the notes

KJSOriginally developed for KDE's Konqueror browser.
ChakraAssociated in the notes with Internet Explorer and Microsoft Edge.
NashornOpen-source engine included as part of OpenJDK.

How a JavaScript engine works

The lecture diagram presents a simplified processing flow from source code to executable code.

JavaScript code→Parser→Abstract Syntax Tree→Interpreter / Bytecode→Optimising compiler

Profiling information can be used to optimise frequently executed code. The engine may de-optimise code when its assumptions no longer hold.

How JavaScript runs while a page loads

  1. The browser requests an HTML page from the server.
  2. The browser reads and renders HTML until it encounters a JavaScript section.
  3. The JavaScript interpreter processes the script until the closing script tag.
  4. The browser continues reading and rendering the remaining HTML.

String literals and quoting

A string literal is a sequence of characters enclosed in matching single or double quotation marks. A number enclosed in quotes is a string, not a number. An empty pair of quotes is an empty (null) string.

var place1 = "Kuala Terengganu";
var place2 = 'Kuala Terengganu';
var quote  = "This is 'JavaScript'";
var number = "8";  // String
var value  = 8;    // Number

06
Storing values

Variables and constants

A variable stores a value that can be used by a program. In the lecture examples, variables are declared using var. A variable can be declared first and assigned a value later, or initialised when it is declared.

var num1;
var town;
var x1;

num1 = 8;
town = "Kuala Terengganu";
x1 = 5.46;

// Declaration with initial values
var length = 16;
var lastName = "Johnson";
var cars = ["Saab", "Volvo", "BMW"];
Good practice: Declare variables before using them. The lecture example identifies using x1 without a declaration as an error in that example.

Undefined and null

A declared variable without an assigned value is undefined. The notes show that typeof null returns "object" in JavaScript.

var x;              // undefined
x = 5;              // number
x = "John";         // string

typeof undefined;   // "undefined"
typeof null;        // "object"

Constants

A constant is declared using const. Its binding cannot be reassigned during program execution.

const GRAM = 1000;
const MYR = 5.45;
var weight = 5 * GRAM;
var currency = 10 * MYR;

Expressions

Operators

Operators manipulate operands. An expression combines values, variables and operators. An assignment statement evaluates the expression on the right-hand side and assigns the result to the variable on the left-hand side.

Arithmetic operators

Other operator groups

Increment / decrement

++ increases a value by one; -- decreases it by one.

Concatenation

The + operator joins strings when one or both operands are strings.

Comparison

==, ===, !=, >, <, >=, <= compare values.

Logical

&& (AND), || (OR), ! (NOT) combine or reverse conditions.

Conditional statements

  // statements
} else if (condition2) {
  // statements

Repetition

Looping

Loops repeat a block of statements. The lecture introduces three types of looping statements.

while

Checks the condition before executing the loop body.

while (condition) {
  statements;
}
for

Combines initialisation, condition and update in one statement.

for (var i=0; i<5; i++) {
  statements;
}
do...while

Executes the loop body first, then checks the condition.

do {
  statements;
} while (condition);

Reusable code

Functions

A function is a self-contained unit of a program designed to accomplish a specific task. It can accept input through parameters, execute statements and optionally return a value. Functions can be reused whenever they are needed.

Input / Arguments→Function→Output / Return value

Function definition and function call

// Function definition
function function_name(param1, param2) {
  statement1;
  statement2;
  return value; // optional
}

// Function call
var output1 = function_name(value1, value2);

Simple function

function welcome() {
  var place = "Pulau Perhentian";
  alert("Welcome to " + place + "!");
}
welcome();

Function with a parameter and return value

function tempConversion(temp) {
  var result = (temp - 32) * (5 / 9);
  return result;
}

var celsius = tempConversion(98.6);

Calling a function from an event

A function can be called when a user interacts with a page, such as clicking a button or a link.

<button onclick="greeting('Student')">Welcome</button>

<script>
function greeting(yourname) {
  alert("Welcome to CSF3133 course, " + yourname);
}
</script>
