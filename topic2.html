🌳INFORMATION STRUCTURE

Website organization

Pages can be arranged hierarchically, linearly or through a more random web of links.

Hierarchical: university site with main sections and subpages. Linear: step-by-step tutorial. Random/web-like: interconnected creative resources. Choose a structure that matches the site's purpose.
◈VISUAL COMMUNICATION

Design principles

Repetition, contrast, proximity and alignment help pages feel organised and easier to scan.

Repetition: consistent buttons. Contrast: clear emphasis. Proximity: related items grouped together. Alignment: edges and text follow a visual line.
♿INCLUSIVE EXPERIENCE

Accessibility

Design content and controls so more people can perceive, understand and operate the website.

Examples include meaningful alternative text, sufficient text contrast, keyboard access, clear headings and descriptive link labels. Use WCAG as a reference when evaluating a site.
💬 Think–Pair–Share

Imagine a university website with 15 unrelated menu links, tiny text and low contrast. Which two changes would you make first, and why?

Possible answers: group navigation into meaningful sections, establish a clear hierarchy, improve text size and contrast, and keep labels descriptive. Explain choices in relation to user needs.

OFFICIAL W3C GUIDANCE

Web Content Accessibility Guidelines (WCAG) 2.2

WCAG organises accessibility guidance around four principles: content should be Perceivable, Operable, Understandable and Robust (POUR).

Read WCAG 2.2 ↗WCAG Quick Reference ↗WCAG Overview ↗
PPerceivableUsers can perceive the information.
OOperableControls and navigation can be operated.
UUnderstandableInformation and interactions are clear.
RRobustContent works with user agents and assistive technologies.
