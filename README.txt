CSF3133 — Web-Based Interface Design course website

FILES
- index.html  Main website structure and course content
- style.css   Responsive layout, typography, colour system, light/dark theme
- script.js   Mobile navigation, topic search, theme toggle, interactive group evaluation checklist

HOW TO RUN
1. Extract the ZIP file.
2. Keep index.html, style.css and script.js in the same folder.
3. Double-click index.html to open it in a modern browser.
4. No build tools or server are required.

CONTENT BASIS
Course information is based on the uploaded “01 Introduction to CSF3133” slides.
The course assessment graphic groups assessment names across CLOs while the cards show the CLO breakdown as presented in the slides.
The instructor contact shown on the website is the email included in the course slides.

NOTES
- The design uses Google Fonts when internet access is available; system fallbacks are included.
- The website evaluation checklist runs in the browser. It does not submit or store student data on a server.
