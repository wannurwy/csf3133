02
Introduction

What is JavaScript?

The language that makes webpages interactive

JavaScript (JS) is a high-level programming language used to make web pages interactive and dynamic. It allows a webpage to respond when a user clicks a button, enters information, submits a form or performs another action.

Programming language

JavaScript gives instructions to a computer to perform tasks and solve problems.

Interactive webpages

It responds to user actions such as clicking, typing, selecting and submitting.

Works with HTML and CSS

It can access webpage elements, change their content and update their appearance.

HTML, CSS and JavaScript work together

Think of a webpage as a person: HTML provides the body structure, CSS determines the appearance, and JavaScript makes things happen.

HTML — Structure

Defines what appears on the webpage, such as headings, paragraphs, images and buttons.

Example: a button exists on the page.
CSS — Presentation

Controls how the webpage looks, including colours, fonts, spacing and layout.

Example: the button is blue with rounded corners.
JavaScript — Behaviour

Controls what happens when users interact with the webpage.

Example: clicking the button displays a message.
Easy way to remember: HTML builds the structure, CSS styles the webpage, and JavaScript adds behaviour and interactivity.

What can JavaScript do?

Display messages

Show a welcome message when a button is clicked.

Validate forms

Check whether required information has been entered correctly.

Perform calculations

Calculate totals, discounts, grades or temperatures.

Update webpage content

Change text, images or styles in response to user actions.

How JavaScript runs while a page loads

  1. The browser requests an HTML page from the server.
  2. The browser reads and renders HTML until it encounters a JavaScript section.
  3. The JavaScript interpreter processes the script until the closing script tag.
  4. The browser continues reading and rendering the remaining HTML.

Values and strings

Data types and string literals

JavaScript data types can be grouped into primitive and composite (non-primitive) types.

String literals and quoting

A string literal is a sequence of characters enclosed in matching single or double quotation marks. A number enclosed in quotes is a string, not a number. An empty pair of quotes is an empty (null) string.

var place1 = "Kuala Terengganu";
var place2 = 'Kuala Terengganu';
var quote  = "This is 'JavaScript'";
var number = "8";  // String
var value  = 8;    // Number

Storing values

Variables and constants

A variable stores a value that can be used by a program. Variables can be declared using var. A variable can be declared first and assigned a value later, or initialised when it is declared.

var num1;
var town;
var x1;

num1 = 8;
town = "Kuala Terengganu";
x1 = 5.46;

// Declaration with initial values
var length = 16;
var lastName = "Johnson";
var cars = ["Saab", "Volvo", "BMW"];
Good practice: Declare variables before using them. Using x1 without a declaration as an error in that example.

Undefined and null

A declared variable without an assigned value is undefined. In JavaScript, typeof null returns "object" in JavaScript.

var x;              // undefined
x = 5;              // number
x = "John";         // string

typeof undefined;   // "undefined"
typeof null;        // "object"

Constants

A constant is declared using const. Its binding cannot be reassigned during program execution.

const GRAM = 1000;
const MYR = 5.45;
var weight = 5 * GRAM;
var currency = 10 * MYR;

Operators

Operators manipulate operands. An expression combines values, variables and operators. An assignment statement evaluates the expression on the right-hand side and assigns the result to the variable on the left-hand side.

Increment / decrement

Concatenation

Comparison

==, ===, !=, >, <, >=, <= compare values.

Logical

Repetition

Looping

Loops repeat a block of statements. The lecture introduces three types of looping statements.

while

Checks the condition before executing the loop body.

while (condition) {
  statements;
}
for

Combines initialisation, condition and update in one statement.

for (var i=0; i<5; i++) {
  statements;
}
do...while

Executes the loop body first, then checks the condition.

do {
  statements;
} while (condition);

Reusable code

Functions

A function is a self-contained unit of a program designed to accomplish a specific task. It can accept input through parameters, execute statements and optionally return a value. Functions can be reused whenever they are needed.

Input / Arguments→Function→Output / Return value

Function definition and function call

// Function definition
function function_name(param1, param2) {
  statement1;
  statement2;
  return value; // optional
}

// Function call
var output1 = function_name(value1, value2);

Simple function

function welcome() {
  var place = "Pulau Perhentian";
  alert("Welcome to " + place + "!");
}
welcome();

Function with a parameter and return value

function tempConversion(temp) {
  var result = (temp - 32) * (5 / 9);
  return result;
}

var celsius = tempConversion(98.6);

Calling a function from an event

A function can be called when a user interacts with a page, such as clicking a button or a link.

<button onclick="greeting('Student')">Welcome</button>

<script>
function greeting(yourname) {
  alert("Welcome to CSF3133 course, " + yourname);
}
</script>
