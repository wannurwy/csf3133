What this course is about

From understanding users to building a simple website, develop the foundations of web interface design.

✳
COURSE SYNOPSIS

Design for people.
Build for the web.

This course introduces basic Human–Computer Interaction (HCI) concepts and web design. You will practise using HTML and CSS, then apply user-centred design principles and methods to develop a simple website.
