What is CSS?

CSS stands for Cascading Style Sheets. It describes how HTML elements should appear on screen, paper or other media.

Purpose

Separate content from presentation

HTML defines the structure and content. CSS controls colour, spacing, borders, typography and layout.

Efficiency

Reuse styles

An external stylesheet can control the appearance of multiple pages from one CSS file.

CSS syntax

A CSS rule contains a selector and a declaration block. Each declaration is written as a property, a colon, a value and a semicolon.

h1 {
  color: blue;
  font-size: 32px;
}
Remember: the selector identifies which HTML element to style. The declaration block is enclosed in curly braces { }; declarations are separated by semicolons.

Types of Graphics

Choose a format based on the image content, transparency needs, animation and file size.

GIF

GIF

Supports simple animation and lossless compression, but is limited to 256 colours per image.

Best for: simple graphics and short animations.

JPEG / JPG

JPEG

Uses lossy compression and supports millions of colours. It is well suited to photographs.

Photo-like gradient sample

Best for: photographs where small file size matters.

PNG

PNG

Uses lossless compression and supports transparency, including varying levels of transparency.

Transparent colour

Best for: graphics that need crisp edges or transparency.

HTML Images & Accessibility

The <img> element displays an image. Its src specifies the file, while alt provides a text alternative.

<img src="images/dog.jpg"
     alt="A dog walking on a path"
     width="300" height="200">

Image attributes

  • src: path to the image file.
  • alt: meaningful alternative text, not merely a filename.
  • width and height: display dimensions.

Image links and thumbnails

<a href="large-photo.jpg">
  <img src="small-photo.jpg"
       alt="Country road thumbnail"
       width="200" height="100">
</a>

A thumbnail is a small image that links to a larger version.

Accessibility: use descriptive alt text for meaningful images. Use alt="" for purely decorative images. Do not rely on colour alone to communicate information, and provide text links if image links are used for navigation.

Image optimisation checklist

Reduce file size

Compress images while retaining acceptable visual quality.

Crop to display dimensions

Avoid serving unnecessarily large images for small spaces.

Use clear filenames

Use lowercase, short descriptive names, avoid spaces and punctuation, and keep the correct extension.

Organise image files

Keep graphics in a dedicated folder and use correct relative paths such as images/home.gif.

<img src="images/home.gif" alt="Home" width="200" height="100">

CSS Background Images

The background-image property places an image behind an element. By default, background images repeat in both directions.

body {
  background-image: url("background.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}

Background playground

Background preview

Repeat values

  • repeat: tiles in both directions.
  • repeat-x: tiles horizontally.
  • repeat-y: tiles vertically.
  • no-repeat: displays once.

Multiple backgrounds

body {
  background:
    url("footer.png") no-repeat bottom right,
    url("gradient.png");
}

When multiple backgrounds are used, the first listed image is painted on top of later images.

Image Resources & Web Design Guidelines

Use suitable, licensed graphics and optimise them for speed, clarity and accessibility.

Graphic sources

  • Create images using graphics software.
  • Take photographs or scan drawings.
  • Use free image libraries such as Unsplash, Pexels and Pixabay.
  • Purchase professional graphics or commission a designer.

Always check the licence and attribution requirements before reuse.

Favicon

A small square icon associated with a website. It may appear in the browser tab or bookmarks.

<link rel="icon"
      href="favicon.ico"
      type="image/x-icon">

CSS sprites

A sprite combines multiple small graphics into one image. CSS positions the image to reveal the required portion, reducing separate image requests in traditional implementations.

Image guidelines

  • Reuse suitable assets where possible.
  • Compress and resize images.
  • Specify width and height to reduce layout shifts.
  • Use lazy loading for off-screen images when appropriate.
  • Check brightness, contrast and text readability.
  • Provide alt text and do not rely on colour alone.

RGBA & HSLA Colours

RGBA uses red, green, blue and alpha. HSLA uses hue, saturation, lightness and alpha.

RGBA

Red, Green, Blue, Alpha

RGB components range from 0 to 255. Alpha ranges from 0 (transparent) to 1 (opaque).

color: rgba(255, 0, 0, 0.5);
HSLA

Hue, Saturation, Lightness, Alpha

Hue ranges from 0–360 degrees. Saturation and lightness are percentages. Alpha ranges from 0–1.

background: hsla(210, 80%, 50%, 0.7);

CSS3 Gradients

A gradient blends colour shades smoothly. CSS supports linear and radial gradients.

Linear gradient

Colours blend along a straight line.

background-image:
  linear-gradient(to right, white, #8FA5CE);

Radial gradient

Colours blend outwards from a central point.

background-image:
  radial-gradient(circle, white, #8FA5CE);
Gradient preview
background-image: linear-gradient(90deg, #ffffff, #8FA5CE);
