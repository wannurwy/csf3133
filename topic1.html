🌐THE INFRASTRUCTURE

Internet

A global network of connected networks that allows devices to communicate and exchange data.

Internet services include the Web, email, voice/video calls, and file transfer. The Internet is not just websites.
🧭A SERVICE ON THE INTERNET

World Wide Web

A system of linked pages and resources that people access through web browsers over the Internet.

Opening a university portal or reading an online article in a browser is using the Web.
🧩WORKING TOGETHER

Browser + Server

The browser requests a resource; the web server processes the request and returns a response.

When you open a course website, the browser asks for its files and then displays the page.
💬 Think–Pair–Share

“Can we use the Internet without using the Web?” Think for 30 seconds, discuss with a partner, then share one example.

Yes. Email and some voice/video communication services can use the Internet without being web pages. The Web is one service that runs on the Internet.
