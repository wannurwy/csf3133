Overview of Cascading Style Sheets

What CSS does and why it is useful

Style sheets were used in desktop publishing to apply typographical styles and spacing to printed media. CSS brings style-sheet functionality to web developers. It is a flexible, cross-platform, standards-based language developed by the W3C.

Greater design control

More control over typography and page layout than HTML alone.

Separate style from structure

Presentation rules can be moved out of the HTML document.

Reusable styles

One stylesheet can be associated with multiple web pages.

Easier maintenance

Update presentation in a stylesheet rather than editing many individual pages.

02

CSS syntax and colour

Selectors, declarations, RGB and hexadecimal values

A CSS rule describes the styling to apply. Each rule contains a selector and a declaration block. A declaration contains a property and a value.

body {
  color: blue;
  background-color: yellow;
}

The same colours can be written using hexadecimal values:

body {
  color: #0000FF;
  background-color: #FFFF00;
}
Remember: write each declaration as property: value;. Separate multiple declarations with semicolons and enclose the declarations in curly braces.

RGB and hexadecimal colours

Monitors display colour using intensities of red, green and blue (RGB). Each RGB value ranges from 0 to 255. Hexadecimal numbers use base 16; each pair ranges from 00 to FF. Three pairs describe one RGB colour.

04

Configuring colour with inline CSS

Use the style attribute on an HTML element

Inline CSS is configured in the body of a web page. It uses the style attribute and applies only to the specific HTML element.

<h1 style="color:#ff0000">
  Heading text is red
</h1>

More than one declaration can be placed in the attribute. Separate declarations with a semicolon.

<h1 style="color:#FF0000; background-color:#CCCCCC">
  Red heading with grey background
</h1>

05

CSS embedded (internal) styles

Use the style element in the head section

Embedded styles are configured in the header section of a web page using the HTML <style> element. The rules apply to the entire web page document.

<head>
  <style>
    body {
      background-color: #000000;
      color: #FFFFFF;
    }
  </style>
</head>

The body selector can set global rules. Rules for more specific elements, such as h1 and h2, can override those global styles.

Configuring text with CSS

Font and text formatting properties

Font properties

  • font-weight: boldness
  • font-style: italic style
  • font-size: text size
  • font-family: typeface

Other text properties

  • line-height: height of text lines
  • text-align: text alignment
  • text-indent: first-line indentation
  • text-decoration: underline, overline, line-through
  • text-transform: capitalization
  • text-shadow: text shadow
Accessibility recommendation in the lecture: use em or percentage font sizes so users can enlarge text in browsers.

Not everyone has the same fonts installed. Configure a list of fonts and include a generic family name.

p {
  font-family: Arial, Verdana, sans-serif;
}

CSS selectors

Element, class, ID and descendant selectors
Selector typeSyntaxWhat it selects
HTML elementpAll paragraph elements.
Class.classnameElements assigned that class; can be reused.
ID#idnameThe element assigned that ID; intended for one element on the page.
Descendant / contextual#content pParagraph elements located inside the element with ID content.

Class selector

A class selector applies a CSS rule to a certain class of elements. It is not tied to one particular HTML element.

.new {
  color: red;
  font-style: italic;
}

/* HTML */
<p class="new">This text is red and italic.</p>

ID selector

An ID selector applies a CSS rule to one element on a web page.

#new {
  color: red;
  font-size: 1.5em;
  font-style: italic;
}

/* HTML */
<p id="new">This text is red, large and italic.</p>

Descendant (contextual) selector

Specify an element within the context of its container (parent) element. Contextual selectors can reduce the number of classes and IDs needed in the HTML.

#content p {
  color: green;
}

The span element

Format a section of text within a line

The <span> element configures a specially formatted area displayed inline with other content, such as a phrase within a paragraph. It does not add extra space above or below the text.

<style>
.companyname {
  font-weight: bold;
  font-family: Georgia, "Times New Roman", serif;
  font-size: 1.25em;
}
</style>

<p>Your needs are important to us at
  <span class="companyname">Acme Web Design</span>.
  We will work with you to build your Web site.
</p>

09

External style sheets

Keep CSS rules in a separate .css file

An external stylesheet is a text file separate from the HTML documents. It has a .css extension, contains CSS rules only, and does not contain HTML tags. Multiple web pages can use the same stylesheet.

color.css
body {
  background-color: #0000FF;
  color: #FFFFFF;
}
HTML head
<head>
  <link rel="stylesheet"
        href="color.css">
</head>

The <link> element is placed in the head section. It associates the external stylesheet with the web page.

Example: to use an external stylesheet named mystyles.css, add <link rel="stylesheet" href="mystyles.css"> inside the HTML <head>.

Centering page content with CSS

#container {
  margin-left: auto;
  margin-right: auto;
  width: 80%;
}

The automatic left and right margins centre a container with a specified width.

The CSS cascade

How CSS decides which style is applied

The cascading order is a set of rules that determines which style is applied to an element when multiple styles conflict.

1. Specificity

More specific selectors take precedence over less specific selectors. An ID selector has higher specificity than a class selector or an element selector.

2. Inheritance

Styles applied to a parent can be passed to its children. A child can override an inherited style with its own rule.

3. Order of declaration

When rules have the same specificity, a later declaration takes precedence over an earlier one.

About !important

The lecture introduces !important as a way to give a declaration priority. Avoid using it unless absolutely necessary.

Specificity example

.container { color: green; }
#text       { color: red; }
.text       { color: green; }

/* An element matching #text receives red text
   because the ID selector is more specific. */

Inheritance example

body {
  background-color: yellow;
  color: black;
}
h2 {
  background-color: green;
  color: white;
}

Order of declaration example

.text { color: blue; }
.text { color: green; }

/* The later rule wins when specificity is equal. */

W3C CSS validation

Check stylesheet syntax

CSS validation checks whether a stylesheet follows CSS syntax rules. The lecture concludes by highlighting the W3C CSS Validation test.

W3C CSS Validation Service

Use the official validator to check a public stylesheet URL, upload a CSS file, or paste CSS code.
