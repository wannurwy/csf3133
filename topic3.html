LECTURE NOTES

HTML learning modules

Follow the modules in order. The examples introduce common HTML patterns and are intended for learning and practice.

1

Introduction to HTML

What HTML is, who reads it, and how HTML works with CSS and JavaScript.

2

Elements, tags and attributes

Opening and closing tags, element content, attributes and nesting.

3

HTML document structure

DOCTYPE, html, head, title, body and the role of each section.

4

Text and content elements

Headings, paragraphs, line breaks, quotations and meaningful content.

5

Lists and grouping

Ordered lists, unordered lists, description lists and grouping content.

6

Hyperlinks and navigation

Anchor elements, link destinations, relative paths and email links.

7

Validation and good practice

Check markup, use semantic elements and fix common syntax mistakes.

Example: a simple HTML page

HTML uses elements to describe the role of content.

<!-- A basic HTML document -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Welcome</h1>
    <p>Hello, HTML!</p>
  </body>
</html>
Remember: HTML describes structure and meaning; CSS styles the page, and JavaScript can add behaviour.
